Acerca de este Roadmap

Esta guía avanzada y detallada te llevará a través del ecosistema completo de DevOps, modernizado con el poder de la Inteligencia Artificial. Desde la conceptualización y automatización de procesos hasta la observabilidad y las operaciones autónomas. Abajo encontrarás el esquema original del bootcamp que seguimos en esta guía.

Explora a continuación cada uno de los 10 módulos con una profundidad técnica que te preparará para el mercado actual:

1. Introducción a DevOps + IA

Cultura y Fundamentos

Objetivos de Aprendizaje

Dominar la filosofía DevOps, entender el Value Stream Mapping y asimilar cómo la IA reduce los cuellos de botella en la entrega de valor.

Temario Profundo

  • Cultura CAMS: Cultura, Automatización, Medición y Compartir.
  • SDLC Moderno: Integración de seguridad desde el diseño (Shift-Left).
  • Versionado Avanzado (Git): Estrategias de branching (Trunk-based development vs GitFlow), rebase interactivo, git bisect.
  • Prompt Engineering para DevOps: Técnicas avanzadas (Few-shot, Chain-of-Thought) para obtener código y scripts fiables de LLMs.

Herramientas de IA y Casos de Uso

Uso de GitHub Copilot para autocompletado de scripts en Bash/PowerShell. Uso de ChatGPT/Claude para explicar mensajes de error de Git, redactar convenciones de commits (Conventional Commits) y generar documentación de arquitectura (Markdown/Mermaid).

Proyecto Práctico 1:

Inicia un repositorio local. Usa una IA generativa para crear un hook de pre-commit en Python que valide que todos los mensajes de commit sigan el estándar 'Conventional Commits' antes de permitir el commit. Pídele a la IA que explique la expresión regular utilizada.

2. Nube en AWS + IA

Arquitectura Cloud

Objetivos de Aprendizaje

Diseñar arquitecturas resilientes y escalables en AWS siguiendo el Well-Architected Framework, apoyándose en IA para seguridad y costos.

Temario Profundo

  • Redes y Seguridad (VPC): Subnets públicas/privadas, NAT Gateways, Security Groups vs NACLs, Route 53.
  • Cómputo Avanzado: Auto Scaling Groups (ASG), Application Load Balancers (ALB), AWS Lambda (Serverless).
  • Almacenamiento y Bases de Datos: S3 (Tiers, Lifecycle policies), RDS Multi-AZ, DynamoDB.
  • Gestión de Identidad (IAM): Principio de mínimo privilegio, roles asumidos, OIDC (OpenID Connect).

Herramientas de IA y Casos de Uso

Utilización de Amazon Q (anteriormente CodeWhisperer) para generar plantillas de CloudFormation o consultas de AWS CLI. Uso de IA para auditar políticas de IAM que son demasiado permisivas y sugerir correcciones. Análisis predictivo de facturación (AWS Cost Explorer AI).

Proyecto Práctico 2:

Diseña una arquitectura de alta disponibilidad de 3 capas. Usa una IA para generar las políticas JSON de IAM estrictamente necesarias (least privilege) para que una instancia EC2 en la capa de aplicación pueda leer un bucket S3 específico y escribir en una tabla de DynamoDB, sin acceso a nada más.

3. Configuración con Ansible + IA

Automatización (Configuration Management)

Objetivos de Aprendizaje

Estandarizar y automatizar el estado de flotas de servidores utilizando Ansible de forma idempotente.

Temario Profundo

  • Arquitectura sin Agentes: Conexiones SSH/WinRM, Inventarios estáticos y dinámicos (AWS EC2 plugin).
  • Desarrollo de Playbooks: Módulos core, condicionales (when), bucles (loop), variables y facts, handlers.
  • Reusabilidad con Roles: Estructura de Ansible Roles, Ansible Galaxy, import_role vs include_role.
  • Seguridad: Gestión de secretos con Ansible Vault.

Herramientas de IA y Casos de Uso

Integración de Ansible Lightspeed con IBM Watsonx Code Assistant. Aceleración del desarrollo de playbooks escribiendo el nombre de la tarea en lenguaje natural ("Install Nginx and start service") y dejando que la IA sugiera el módulo exacto y los parámetros óptimos.

Proyecto Práctico 3:

Escribe un prompt para una IA solicitando la creación de un Rol de Ansible completo (estructura de carpetas, tasks, handlers, vars) que configure un clúster de base de datos PostgreSQL con replicación primaria-secundaria. Revisa el código generado buscando problemas de idempotencia.

4. IaC con Terraform + IA

Infraestructura como Código

Objetivos de Aprendizaje

Dominar el aprovisionamiento declarativo multi-nube y gestionar estados complejos de manera segura.

Temario Profundo

  • Fundamentos HCL: Providers, Resources, Data Sources, Locals.
  • State Management Avanzado: Remote backends (S3 + DynamoDB para state locking), workspaces, manipulación del estado (`terraform state mv/rm`).
  • Modularidad: Creación de módulos reutilizables, registro de módulos, paso de variables e inyección de dependencias.
  • Testing y Seguridad: Herramientas estáticas (TFLint, Checkov) para validar la infraestructura antes de desplegarla.

Herramientas de IA y Casos de Uso

Uso de herramientas como KICS (Keeping Infrastructure as Code Secure) potenciado por IA o HCP Terraform AI. Uso de LLMs para refactorizar código monolítico de Terraform en módulos limpios y parametrizados. Generación automática de documentación de módulos (terraform-docs).

Proyecto Práctico 4:

Proporciona a una IA un fragmento de código Terraform vulnerable (ej. un Security Group con puerto 22 abierto al 0.0.0.0/0 y un bucket S3 público). Pídele que realice una "auditoría de seguridad DevSecOps", identifique las vulnerabilidades y te devuelva el código HCL parcheado siguiendo las mejores prácticas.

5. Contenedores con Docker + IA

Empaquetado y Aislamiento

Objetivos de Aprendizaje

Crear imágenes de contenedores ligeras, seguras y eficientes para entornos de microservicios.

Temario Profundo

  • Internals de Linux: Namespaces (aislamiento) y Cgroups (limitación de recursos).
  • Dockerfiles Avanzados: Multi-stage builds para lenguajes compilados (Go, Java), distroless images, gestión de caché de capas (Layer caching).
  • Docker Compose: Definición de stacks locales, redes personalizadas (bridge, overlay), volúmenes con nombre.
  • Seguridad en Contenedores: Escaneo de vulnerabilidades en imágenes (Trivy), ejecución como usuario no root.

Herramientas de IA y Casos de Uso

Uso de Docker AI / GitHub Copilot for Docker para autocompletar Dockerfiles. Optimización asistida por IA para reducir la superficie de ataque recomendando imágenes base más seguras (ej. Alpine vs Ubuntu) y reordenando instrucciones para optimizar la caché de compilación.

Proyecto Práctico 5:

Pide a una IA que analice un Dockerfile monolítico (ej. una app Node.js pesada) y te genere la versión equivalente utilizando Multi-stage builds y la imagen base de Google Distroless. Compara el peso (en MB) de la imagen resultante teórica.

6. Orquestación con Kubernetes + IA

Orquestación a Gran Escala

Objetivos de Aprendizaje

Gestionar clústeres de K8s, entender la auto-recuperación y desplegar arquitecturas complejas tolerantes a fallos.

Temario Profundo

  • Arquitectura Interna: etcd, kube-apiserver, kube-scheduler, kubelet, Kube-proxy.
  • Workloads Complejos: StatefulSets, DaemonSets, Jobs, CronJobs.
  • Gestión de Tráfico y Red: Ingress Controllers (Nginx, Traefik), Network Policies (aislamiento de pods), Service Mesh (Istio/Linkerd).
  • Gestión de Configuración: Helm Charts avanzados, Kustomize.

Herramientas de IA y Casos de Uso

Herramientas como K8sGPT: una herramienta de CLI que utiliza IA para escanear clústeres de Kubernetes, diagnosticar pods fallidos (CrashLoopBackOff), explicar los logs de error en lenguaje natural y sugerir el parche exacto (YAML) para solucionarlo.

Proyecto Práctico 6:

Simula un error común (ej. `OOMKilled` o `ImagePullBackOff`) en un Pod. Proporciona los eventos (`kubectl describe pod`) a una IA y pídele que actúe como una herramienta de diagnóstico (tipo K8sGPT) para explicarte la causa raíz y darte los pasos de mitigación inmediatos.

7. CI/CD con GitHub Actions + IA

Entrega Continua (GitOps)

Objetivos de Aprendizaje

Diseñar pipelines de integración y despliegue continuos eficientes, seguros e inteligentes.

Temario Profundo

  • Diseño de Pipelines: Paralelización de Jobs, matrices de pruebas, cachés de dependencias para acelerar tiempos de build.
  • Gestión de Entornos: Secrets, variables, aprobaciones manuales y despliegues condicionales basados en ramas.
  • Acciones Personalizadas: Creación de Custom GitHub Actions en JavaScript o Docker.
  • GitOps (Introducción): Integración con ArgoCD o Flux para reconciliar el estado del clúster con Git.

Herramientas de IA y Casos de Uso

Revisión de Código Asistida (AI Code Reviewers): Bots de IA que analizan automáticamente Pull Requests, sugieren mejoras de rendimiento, detectan bugs de seguridad antes de fusionar el código y escriben resúmenes del PR de forma automática.

Proyecto Práctico 7:

Utiliza ChatGPT para diseñar el código YAML de un workflow de GitHub Actions que: 1) Ejecute linters, 2) Corra tests unitarios en 3 versiones diferentes de Python (Matriz), 3) Construya una imagen Docker, 4) La escanee con Trivy, y 5) Solo si es la rama `main`, la suba a Docker Hub.

8. Observabilidad con Dynatrace + IA

AIOps y Monitoreo Proactivo

Objetivos de Aprendizaje

Pasar del simple monitoreo (saber qué falló) a la observabilidad (entender por qué falló) utilizando AIOps.

Temario Profundo

  • Telemetría (OpenTelemetry): Estandarización de métricas, logs y trazas distribuidas (Distributed Tracing).
  • Monitoreo Sintético y RUM: Real User Monitoring y simulaciones de usuario.
  • SLIs, SLOs y Error Budgets: Definición de métricas de fiabilidad orientadas al negocio (SRE practices).
  • Plataformas Modernas: Uso avanzado de Dynatrace, Datadog o Prometheus/Grafana stack.

Herramientas de IA y Casos de Uso

Davis AI (Dynatrace) o Datadog Watchdog: Inteligencia artificial determinística o machine learning que ingiere millones de puntos de datos. Aprende automáticamente las "líneas base" (baselines) normales, detecta anomalías antes de que el usuario lo note y traza el árbol de fallos (Fault Tree Analysis) hasta la línea de código exacta causante del problema, eliminando las tormentas de alertas.

Proyecto Práctico 8:

Investiga y redacta un pequeño documento explicando cómo una herramienta AIOps diferencia entre un pico de tráfico legítimo (ej. Black Friday) y un ataque DDoS o un bug de memoria (Memory Leak), sin requerir que el ingeniero DevOps configure umbrales manuales estáticos.

9. CV, Entrevistas y Marca Personal + IA

Desarrollo Profesional

Objetivos de Aprendizaje

Posicionarse como un Ingeniero DevOps / SRE altamente atractivo para reclutadores de empresas tecnológicas Top.

Temario Profundo

  • Optimización de CV (ATS Friendly): Uso de metodologías como XYZ ("Logré X, medido por Y, haciendo Z") enfocadas en impacto empresarial y ahorro de costos.
  • Portafolio DevOps: Proyectos clave que debes tener en GitHub (Infraestructura real, pipelines funcionales).
  • La Entrevista de System Design: Cómo abordar entrevistas de arquitectura (Estimaciones, escalabilidad, cuellos de botella).
  • Entrevista de Comportamiento (Metodología STAR): Situation, Task, Action, Result.

Herramientas de IA y Casos de Uso

Sistemas como Teal o ResumeAI para adaptar instantáneamente el CV a la descripción del trabajo (Job Description). Uso avanzado del modo voz de ChatGPT para simular entrevistas de System Design bajo presión de tiempo, recibiendo feedback en tiempo real sobre claridad y profundidad técnica.

Proyecto Práctico 9:

Copia y pega la descripción de una vacante real de "Senior DevOps Engineer" en una IA. Pídele que extraiga las 5 tecnologías/habilidades clave (keywords) y que te simule una entrevista técnica con 3 preguntas difíciles basadas exclusivamente en esos requerimientos.

10. DevOps + IA en la industria (El Futuro)

Tendencias y Evolución

Objetivos de Aprendizaje

Prepararse para el cambio de paradigma: de la administración de sistemas al Platform Engineering impulsado por IA.

Temario Profundo

  • Platform Engineering: Creación de Portales de Desarrollador Internos (IDPs como Backstage) para ofrecer infraestructura como autoservicio (Self-Service).
  • DevSecOps e IA: Modelos predictivos para identificar patrones de amenazas y respuestas automatizadas a incidentes de seguridad (SOAR).
  • FinOps (Cloud Financial Management): Modelos de ML para pronosticar gastos en la nube y detectar anomalías en la facturación en tiempo real.
  • Hacia NoOps: El camino hacia sistemas verdaderamente autónomos que se auto-reparan y auto-escalan sin intervención humana.

Herramientas de IA y Casos de Uso

Integración de Agentes de IA Autónomos (AutoGPT/Devin) en los flujos de trabajo de Platform Engineering. Los desarrolladores pedirán entornos complejos a un chatbot interno de la empresa, y los agentes de IA aprovisionarán cuentas de AWS, repositorios, pipelines y bases de datos automáticamente en minutos, cumpliendo con las políticas de seguridad corporativas.

Proyecto Práctico 10:

Pídele a una IA que actúe como un "Ingeniero FinOps Senior". Dale un caso hipotético donde la factura de AWS subió un 40% en un mes. Pregúntale qué métricas revisaría, qué consultas ejecutaría en Cost Explorer y qué estrategias de optimización inmediatas (Spot instances, Reservas) sugeriría.
